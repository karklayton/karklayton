## Hey  there, I'm Karin ✨
I'm an entrepreneur, inventor, engineer, and tinkerer. I love building things. 

In here lives the projects I am and have worked on.


### IoT Devices

* [BoldHue](https://github.com/karklayton/boldhue) - Co-Founder and CTO for an award winning beauty tech device startup. Device scans skin and creates color matched liquid foundation on demand using motors, pumps, optical color sensors, custom algorithms, database, and BLE companion app.

### Electromechanical prototypes

* [n95 Mask Testing Device](https://github.com/karklayton/n95masktesting) - Device to check the efficiency of n95 masks using motors, particle sensor, and touchscreen display.
* [Eye Dropper Testing Device](https://github.com/karklayton/droptester) - Device to automate testing eye dropper packaging for consistency using a servo and ESP32 control board.
* [Hand Sanitizer Testing Device](https://github.com/karklayton/handsanitizertesting) - Device to test the actual percentage of sanitizers in cleaning solutions using weight sensor, ESP32 control board, and LED display.

### Apps and Websites

* [CyR.U.S. by Victorialand Beauty](https://github.com/karklayton/cyrusapp) - App that enables blind users to identify packaging and get questions answered by a verbal AI assistant using Flutter, OCR, database, and OpenAI webRTC. 
* [ColorWise](https://github.com/karklayton/colorwise) - Co-Founder and CTO for dental resin shade matching startup. Website that analyzed cross-polarized photos of teeth and matches the shade to the closest resin composite in a color database using custom Wix code, algorithms, and database.
